## O que demonstra

Catálogos em carrossel, cartões de destaque, categorias e navegação adaptada para celular e desktop.

## Executar localmente

Na pasta do projeto, inicie um servidor estático:

```bash
python -m http.server 8000
```

Abra `http://localhost:8000`. Não há etapa de build.

## Escopo

É uma vitrine demonstrativa. Busca, favoritos, perfil, sacola e pagamento não formam um fluxo de compra funcional; há links de exemplo. Capas e nomes de álbuns compõem o exercício visual.
